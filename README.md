# ports

My personal ports collection for [CRUX Linux](https://crux.nu/).

Update checking uses [nvc](https://github.com/Gur0v/nvc) with per-port
`.nvc.ini` files. Run `./check-versions` to check all ports, or pass port names
to check individual ones. It reports version differences without modifying ports.
